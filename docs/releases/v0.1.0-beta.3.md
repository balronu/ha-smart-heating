# Smart Heating v0.1.0-beta.3

## Deutsch

Beta 3 ergänzt den passiven Entscheidungs- und Migrationskern. Die bekannte
Heizungspriorität wird serverseitig als nachvollziehbare Entscheidung mit
Modus, Grund, Zieltemperatur und HVAC-Ziel berechnet. Sommer-HVAC-Off ist nur
als konfigurierbare Planung vorgesehen und fällt bei fehlender Unterstützung
auf den Kompatibilitätsmodus zurück.

Der Migrationsadapter unterstützt in isolierten Tests Bestätigung, Snapshot,
Read-back und Rollback. Die produktive Aktivierung bleibt gesperrt, weil die
Simple-Scheduler-Daten und der vollständige alte Schreibpfad über unterstützte
Leseschnittstellen nicht sicher nachgewiesen sind. Keine produktive
Installation, Migration oder Heizungsaktion ist Bestandteil dieser Beta.

## English

Beta 3 adds the passive decision and migration core. The known heating priority
is evaluated server-side as an explainable decision with mode, reason, target
temperature, and HVAC target. Summer HVAC-off is only prepared as a configurable
plan and safely falls back when the thermostat capability is not proven.

The migration adapter supports confirmation, snapshot, read-back, and rollback
in isolated tests. Production activation remains locked because the Simple
Scheduler data and complete legacy writer path cannot be proven through
supported read-only interfaces. No production installation, migration, or
heating action is part of this beta.
