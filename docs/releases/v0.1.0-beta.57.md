# Smart Heating v0.1.0-beta.57

## Deutsch

### Änderungen

- Badezimmer zeigt Raumzieltemperatur, Heizkörperthermostat `climate.heizthermostat_badezimmer` und IR-Heizung `climate.metal_panel_heater` getrennt.
- IR-Zustand, Sollwert und Komfortwert werden separat dargestellt; `unknown`/`unavailable` wird nur aus dem tatsächlichen HA-State als „Nicht erreichbar“ markiert.
- Doppelte globale Temperaturregler sind aus der produktiven Übersicht entfernt und nur noch als klar markierte Legacy-Testwerte erreichbar.
- Sondermodi werden in einer gemeinsamen passiven Übersicht geführt; Diagnose bleibt standardmäßig eingeklappt.

### Kompatibilität und Migration

- Bestehende Zonen, Entitätszuordnungen, Wochenprogramme und Sondermodus-Konfigurationen bleiben erhalten.
- Es werden keine Climate-Serviceaufrufe ausgeführt; die bestehende Heizungsautomation bleibt aktiv.

### Einschränkungen

- Produktive HVAC-Modi konnten wegen `CONNECTION_TIMEOUT` nicht live verifiziert werden.
- Beta.57 bleibt ein passives HACS-Pre-Release.

## English

### Changes

- Bathroom room target, radiator thermostat `climate.heizthermostat_badezimmer`, and infrared heater `climate.metal_panel_heater` are rendered separately.
- Infrared state, setpoint, and comfort value are shown independently; “Not reachable” is derived only from the actual HA entity state.
- Duplicate global temperature controls are removed from the productive overview and remain available only as clearly marked legacy test values.
- Special modes use one shared passive overview; diagnostics are collapsed by default.

### Compatibility and migration

- Existing zones, entity assignments, weekly schedules, and special-mode configuration are preserved.
- No Climate service calls are made; the existing heating automation remains active.

### Limitations

- Production HVAC modes could not be verified because of `CONNECTION_TIMEOUT`.
- Beta.57 remains a passive HACS pre-release.
