# Smart Heating v0.1.0-beta.14

## Deutsch

Beta 14 behebt den HTTP-500-Fehler beim Öffnen des Options-/Konfigurationsflusses
unter Home Assistant 2026.10. Der Wochenplan wird jetzt über einen nativen,
serialisierbaren Object-Selector beschrieben. Die Korrektur betrifft nur das
Flow-Schema; Heizungsautomationen, Heizungsbefehle, Simple Scheduler und Tado
bleiben unverändert.

Regressionen für bestehende Entries, die `already_configured`-Sperre und die
HA-Schema-Serialisierung sind enthalten. Die Veröffentlichung autorisiert
keine automatische Installation auf VM 104.

## English

Beta 14 fixes the HTTP 500 raised when opening the options/configuration flow on
Home Assistant 2026.10. The weekly schedule now uses a native serializable
Object Selector. The fix is limited to the flow schema; heating automations,
heating commands, Simple Scheduler, and Tado remain unchanged.

Regression coverage includes existing entries, the `already_configured` guard,
and Home Assistant schema serialization. Publishing this release does not
authorize automatic installation on VM 104.
