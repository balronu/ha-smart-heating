# v0.1.0-beta.10

## Deutsch

Beta 10 korrigiert die mobile Ersteinrichtung und die Entity-Erkennung.

- Der initiale Config Flow fragt nur Name und Zeitzone ab.
- Discovery-Vorschläge werden erst nach ausdrücklicher Bestätigung gespeichert.
- Anwesenheit verwendet ausschließlich native `person.*`-Entities.
- Fensterkandidaten sind auf geeignete `binary_sensor`-Öffnungszustände begrenzt.
- Die sieben Backend-Bereiche bleiben standardmäßig geschlossen; Raumdetails sind verschachtelt aufklappbar.
- Passivmodus, bestehende Heizungsautomation und Simple Scheduler bleiben unverändert.

Die Lovelace-/Runtime-Prüfungen laufen in isolierten Fixtures. Ein produktives
Update auf VM 104 ist nicht Bestandteil dieses Releases.

## English

Beta 10 improves mobile first-run setup and entity discovery.

- The initial Config Flow asks only for a name and time zone.
- Discovery suggestions are stored only after explicit confirmation.
- Presence uses native `person.*` entities exclusively.
- Window candidates are limited to suitable opening `binary_sensor` states.
- The seven backend sections are closed by default; room details are nested and expandable.
- Passive mode, the existing heating automation, and Simple Scheduler remain unchanged.

The Lovelace and runtime checks run in isolated fixtures. A productive update
of VM 104 is not part of this release.
