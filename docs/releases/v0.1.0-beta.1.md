# Smart Heating v0.1.0-beta.1

## Deutsch

### Inhalt

- UI-basierter Config Flow und Options Flow.
- Persistente Wochenzeitpläne mit mehreren validierten Fenstern je Tag.
- Serverberechnung von aktivem Zeitplan, Betriebsmodus und nächster Umschaltung.
- Simulationsmodus für die dokumentierte Referenz-Priorität.
- Read-only Diagnose und Migrations-Preview.
- Kompakte responsive Lovelace-Karte mit direkter Planbearbeitung und Kopieren
  zwischen Wochentagen.
- Deutsche und englische Übersetzungen sowie HACS-Metadaten.

### Kompatibilität und Migration

Dies ist ein Entwicklungsrelease für Home Assistant 2026.10 oder neuer. Beta 1
arbeitet passiv: Es schaltet keine Climate-Entity, keinen bestehenden Helper,
keinen Simple Scheduler und keinen Sondermodus. Die bekannten Referenzzeiten
werden nicht automatisch importiert. Eine produktive Migration, Aktivierung oder
Installation in VM 104 ist ausdrücklich nicht enthalten.

### Bekannte Einschränkungen

- Vollständige Migration über produktive Scheduler-/Automationsdaten ist nur als
  Preview vorbereitet.
- Es gibt noch keine konkurrierende Heizungsentscheidung, automatische
  Übernahme von `input_boolean.heizung` oder echte HVAC-Sommerabschaltung.
- Die HA-abhängigen Laufzeitpfade benötigen eine Home-Assistant-Testumgebung;
  die lokale Offline-Suite deckt die reine Planlogik und den Kartenvertrag ab.

### Installation

In HACS Vorabversionen aktivieren und `Smart Heating` installieren. Die Beta
zunächst nur in einer isolierten Testinstanz verwenden.

## English

### Included

- UI-based Config Flow and Options Flow.
- Persistent weekly schedules with multiple validated windows per day.
- Server-side calculation of active schedule, mode, and next transition.
- Simulation mode for the documented reference priority order.
- Read-only diagnostics and migration preview.
- Compact responsive Lovelace card with direct schedule editing and weekday
  copying.
- German and English translations plus HACS metadata.

### Compatibility and migration

This is a development release for Home Assistant 2026.10 or newer. Beta 1 is
passive: it does not switch climate entities, existing helpers, Simple
Scheduler, or special modes. The known reference times are not imported
automatically. Production migration, activation, and installation in VM 104
are explicitly out of scope.

### Known limitations

- Full migration from production scheduler/automation data is prepared only as
  a preview.
- There is no competing heating decision engine, automatic takeover of
  `input_boolean.heizung`, or real HVAC-off summer mode yet.
- HA-dependent runtime paths require a Home Assistant test environment; the
  local offline suite covers the pure schedule logic and card contract.

### Installation

Enable prereleases in HACS and install `Smart Heating`. Use this beta first in
an isolated test instance.
