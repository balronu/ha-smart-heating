# Smart Heating Beta 28

## Deutsch

Beta 28 führt einen universellen, passiven Sondermodus-Manager ein. Bestehende
Sondermodus-Zuordnungen werden ohne Löschen oder Überschreiben in stabile
Konfigurationsobjekte überführt. Benutzerdefinierte Modi können intern verwaltet
oder lesend an geeignete `input_boolean`-Entities gebunden werden. Die Erstellung
neuer HA-Helper ist in dieser Version deaktiviert, da kein sicherer offizieller
API-Pfad im Integrationsvertrag nachgewiesen ist.

Keine produktive Heizungssteuerung, keine Helper-Schreibvorgänge und keine
VM-104-Installation sind Bestandteil dieser Beta.

## English

Beta 28 adds a universal passive special-mode manager. Existing assignments are
migrated into stable configuration objects without deleting or overwriting data.
Custom modes can be managed internally or observe suitable `input_boolean`
entities read-only. New HA-helper creation is disabled because no safe official
API path has been proven for this integration contract.

No productive heating control, helper writes, or VM 104 installation are part of
this beta.
