# v0.1.0-beta.24 – Phase 31 iPhone-Abnahme

## Deutsch

Die Verwaltungsoberfläche wurde für die verbindlichen Phase-31-Befunde
nachgeschärft: Wochenplan-Zeitfelder stapeln sich auf schmalen Viewports,
ungespeicherte Änderungen sind sichtbar, und nach dem Read-back wird der
Speichererfolg bestätigt. Bestehende Zeitfenster und Zieltemperaturen bleiben
unverändert.

Raum-/Klimazonen-Zuordnungen kennzeichnen gespeicherte Auswahl und übernehmen
neue Werte erst nach ausdrücklichem Speichern. Es gibt keinen automatischen
24-°C-Badezimmerwert. Fensterkontakte zeigen Raum, Zustand und Eignung mit
Abständen; unbekannte und nicht verfügbare Zustände werden ausdrücklich
bezeichnet. Sondermodi trennen Konfiguration, Aktivität und Statusquelle; alle
Kontrollflächen bleiben passiv.

## English

The administration UI now covers the Phase 31 acceptance findings: weekly-plan
time fields stack on narrow viewports, unsaved changes are explicit, and a
successful save is confirmed after read-back. Existing windows and target
temperatures remain unchanged.

Room/climate-zone assignments identify saved selections and apply new values
only after explicit save. No implicit 24 °C bathroom value is introduced.
Window contacts separate room, state, and suitability, with explicit unknown
and unavailable labels. Special modes distinguish configuration, activity, and
status-source presence; all controls remain passive.

## Compatibility, installation, and limitations

The integration remains in passive compatibility mode. No Home Assistant area,
entity, helper, automation, scheduler, thermostat, or heating command is
changed by this release. HACS prerelease selection and a current backup are
required before an authorized installation; the later separate Lovelace card
is not part of this beta.
