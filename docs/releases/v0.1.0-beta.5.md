# Smart Heating v0.1.0-beta.5

## Deutsch

Beta 5 ergänzt den sicheren Installationsplan. Kompatibilitätsmodus bleibt
Standard und lässt die bestehende Thermostat-Automation unverändert. Der
Vollmodus bleibt bis zum Nachweis eines Single-Writers in einer isolierten
Umgebung gesperrt. Der isolierte Climate-Pfad liest HVAC-Modus und Ziel-
temperatur zurück und rollt bei Abweichung zurück.

VM 104 wurde ausschließlich gelesen. Kein Brennerbetrieb wurde ausgelöst oder
behauptet. Simple Scheduler stellt über unterstützte Read-only-Schnittstellen
keinen Export seiner internen Zeitpläne bereit; die UI verlangt daher einen
bestätigten manuellen Vorschlag.

## English

Beta 5 adds the safe installation plan. Compatibility mode remains the default
and leaves the existing thermostat automation unchanged. Full mode stays locked
until single-writer proof exists in an isolated environment. The isolated
climate path reads back HVAC mode and target temperature and rolls back on a
mismatch.

VM 104 was read only. No burner operation was triggered or claimed. Simple
Scheduler does not expose an internal schedule export through supported
read-only interfaces, so the UI requires a confirmed manual proposal.
