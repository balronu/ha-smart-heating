# v0.1.0-beta.27 – Phase 35

## Deutsch

Beta 27 ist der letzte Verwaltungs-UX-Feinschliff vor der eigenständigen
Lovelace-Steuerkarte. Sondermodi empfehlen die vorhandenen passenden
`input_boolean`-Entities, speichern aber nichts automatisch und schalten keine
Entity. Weitere Boolean-Quellen bleiben über die kompakte Suche erreichbar.
Der Wochenplan zeigt sieben kompakte Tageszeilen; Bearbeiten öffnet genau einen
Tag, und Speichern kehrt zur Übersicht zurück.

Bestehende Zuordnungen und Wochenplandaten werden erhalten. Fehlende oder nicht
verfügbare Quellen werden ausdrücklich angezeigt. Die Integration bleibt im
passiven Kompatibilitätsmodus; es werden keine Heizbefehle, Thermostate,
Automationen, Helfer, Bereiche oder Originalsensoren verändert.

## English

Beta 27 is the final administration-UX polish before the independent Lovelace
control card. Special modes recommend the suitable existing `input_boolean`
entities, but never save or activate a source automatically. Additional Boolean
sources remain available through the compact search. The weekly planner shows
seven compact day rows; editing opens one day only, and saving returns to the
overview.

Existing assignments and schedules are preserved. Missing or unavailable
sources are explicitly shown. The integration remains in passive compatibility
mode; no heating commands, thermostats, automations, helpers, areas, or source
sensors are changed.
