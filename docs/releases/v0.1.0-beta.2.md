# Smart Heating v0.1.0-beta.2

## Deutsch

### Inhalt

- Konservative automatische Erkennung von Climate, Heizfreigabe,
  Temperatur-Helpern, Fensterkontakten, Anwesenheit und Sondermodi.
- Eindeutige Treffer werden vorgeschlagen; Mehrdeutigkeiten und fehlende Rollen
  bleiben sichtbar und werden nicht blind übernommen.
- Read-only-Migrationsassistent mit den vier bekannten Heizzeitgruppen als
  ausdrücklich markierter Fixture, Konfliktprüfung und validiertem manuellen
  Vorschlagspfad.
- Config Flow und Options Flow gegen Home Assistant 2026.10.4 getestet.
- Entity-Erstellung, ungültige Zeitpläne, Reload und persistierte Optionen in
  einer isolierten HA-Fixture getestet.
- Lovelace-Karte zeigt Planstatus und passiv geschätzten Ist-Modus getrennt und
  besitzt einen Editor-/Picker-Vertrag.

### Sicherheit und Migration

Beta 2 bleibt passiv. Es gibt keinen produktiven Writer, keine Serviceaufrufe an
Heizungs-Entities, keinen Scheduler-Import und keine Migration in VM 104. Ein
Migrationsvorschlag ist nur eine validierte Vorschau; Rollback ist als Konzept
vorbereitet, aber mangels Aktivierung noch nicht ausführbar.

### Bekannte Einschränkungen

- Browser-, iPhone-, iPad- und Touch-Tests sind nicht Bestandteil dieser Beta.
- Die Scheduler-Export-Schnittstelle ist weiterhin nicht als unterstützte
  öffentliche Leseschnittstelle verfügbar.
- Das HACS-Katalog-Listing ist nicht automatisch garantiert; die Installation
  über das Repository bleibt als Fallback dokumentiert.

## English

### Included

- Conservative automatic discovery for climate, heating permission,
  temperature helpers, window contacts, presence, and special modes.
- Unique matches are suggested; ambiguity and missing roles remain visible and
  are never adopted blindly.
- Read-only migration assistant with the four known heating-time groups as an
  explicitly marked fixture, conflict checks, and a validated manual proposal
  path.
- Config Flow and Options Flow tested against Home Assistant 2026.10.4.
- Entity creation, invalid schedules, reload, and persisted options tested in an
  isolated HA fixture.
- Lovelace card separates schedule status from its passive actual-mode estimate
  and provides an editor/picker contract.

### Safety and migration

Beta 2 remains passive. It has no production writer, no heating-entity service
calls, no scheduler import, and no migration into VM 104. A migration proposal
is only a validated preview; rollback is prepared as a concept but cannot run
until activation is explicitly implemented and approved.

### Known limitations

- Browser, iPhone, iPad, and touch tests are not part of this beta.
- The scheduler export is still not available through a supported public
  read-only interface.
- HACS catalog listing is not guaranteed automatically; custom-repository
  installation remains documented as a fallback.
