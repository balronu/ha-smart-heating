# Smart Heating v0.1.0-beta.6

## Deutsch

Beta 6 ergänzt einen reproduzierbaren Playwright-Testpfad mit gerenderter
Lovelace-Karte. Desktop, iPhone-Viewport, iPad und schmaler Touchmonitor
prüfen sichtbare Zeitfelder, Hinzufügen, Ändern, Löschen, Kopieren,
Fehleranzeige, lange Texte und Dark Mode. Screenshots werden als CI-Artefakte
gespeichert.

Der Config Flow zeigt erkannte Zuordnungen vor dem Erstellen in einer separaten
Bestätigungsseite. Der Kompatibilitätsmodus bleibt passiv und schreibt keine
Climate- oder Sondermodus-Entities. Die automatische Erkennung bleibt bei
Mehrdeutigkeiten vorsichtig.

## English

Beta 6 adds a reproducible Playwright path rendering the Lovelace card.
Desktop, iPhone viewport, iPad, and narrow touch monitor cover visible time
fields, add, edit, delete, copy, validation errors, long text, and dark mode.
Screenshots are stored as CI artifacts.

Config Flow presents discovered associations on a separate confirmation page
before creating the entry. Compatibility mode remains passive and writes no
climate or special-mode entities. Discovery stays conservative when roles are
ambiguous.
