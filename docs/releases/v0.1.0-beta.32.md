# Smart Heating v0.1.0-beta.32

## Deutsch

Beta 32 veröffentlicht ausschließlich die Phase-42-Persistenzkorrektur für
Fensterkontaktrollen. Die Auswahl bleibt im Raumformular sichtbar und wird erst
mit „Raum speichern“ übernommen. Der geordnete Save-/Readback-Pfad verhindert,
dass ältere mobile Raumdaten die Rolle wieder auf „Nicht zugeordnet“ setzen.
Bestehende Kontakte und Zuordnungen bleiben erhalten. Der Betrieb bleibt passiv;
es werden keine Heizbefehle, Helper, Automationen, Scheduler oder HA-Entities
verändert.

## English

Beta 32 publishes only the Phase 42 persistence fix for window contact roles.
The selection remains visible in the room form and is applied only with “Save
room”. The ordered save/read-back path prevents older mobile room data from
resetting the role to “Unassigned”. Existing contacts and assignments remain
intact. Operation remains passive; no heating commands, helpers, automations,
schedulers, or HA entities are changed.

## Post-update

Restart Home Assistant only if HACS requests it after installing the exact
`v0.1.0-beta.32` tag. Verify the existing Smart Heating Config Entry and room
assignments before manually changing any role.
