# Smart Heating v0.1.0-beta.33

## Deutsch

Beta 33 veröffentlicht die Phase-44-Korrektur für die Fensterkontaktrollen-
Persistenz. Raumdaten und Rollen werden gemeinsam über `admin/room/save`
gespeichert und anschließend unabhängig aus dem Config Entry zurückgelesen.
Eine Erfolgsmeldung erscheint nur bei übereinstimmendem Readback; Abweichungen
werden sichtbar als Fehler gemeldet. Bestehende Kontakte und Zuordnungen bleiben
erhalten. Der Betrieb bleibt passiv und führt keine Heizbefehle aus.

## English

Beta 33 publishes the Phase 44 fix for window-contact role persistence. Room
data and roles are saved together through `admin/room/save` and independently
read back from the Config Entry. A success message is shown only when the
read-back matches; mismatches are shown as visible errors. Existing contacts
and assignments remain intact. Operation remains passive and sends no heating
commands.

## Post-update

Restart Home Assistant only if HACS requests it after installing the exact
`v0.1.0-beta.33` tag. Verify the existing Smart Heating Config Entry and room
assignments before manually changing any window-contact role.
