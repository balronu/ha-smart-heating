# v0.1.0-beta.60 – Lovelace reference design

## Deutsch

Beta.60 ist eine reine Lovelace-Visual-Iteration auf dem passiven Beta.59-Vertrag. Die Karte zeigt nur Heizungssteuerung, Hauptheizung und Räume. Status- und Sollwertänderungen werden ausschließlich über die interne Config-Entry-Persistenz angefordert; es werden keine Climate-Dienste aufgerufen.

Die Raumdarstellung verwendet ein responsives Grid. Das Badezimmer zeigt Raumziel, Heizkörperthermostat und Infrarotheizung getrennt. Technische Entity-IDs sind in der normalen Ansicht nicht sichtbar.

## English

Beta.60 is a Lovelace-only visual iteration on the passive Beta.59 contract. The card shows heating control, central heating, and rooms only. Status and target changes use internal Config Entry persistence; no Climate services are called.

Room cards use a responsive grid. The bathroom keeps the room target, radiator thermostat, and infrared heater separate. Technical entity IDs are hidden from the normal view.

## Limitations / Einschränkungen

- This release remains passive. It does not replace or actuate the existing heating automation.
- Browser screenshots use isolated fixture data; productive VM 104 was not changed or installed.
- HACS distribution remains source-only; no package asset is generated by this repository.
