# Smart Heating v0.1.0-beta.42

## Deutsch

- Wochenplan: Zeit- und Temperaturfelder behalten beim Tippen den Fokus; kein Re-Render pro Tastendruck.
- Kopieren auf mehrere deutsche, anklickbare Wochentage. Bei bereits belegten Tagen wird vor dem Überschreiben gefragt.
- Zeitangaben ohne Sekunden; kompakter Tageseditor und Speicherstatus.
- Die vorhandene passive Lovelace-Karte bleibt enthalten.
- Legacy bleibt alleiniger Heizungs-Schreiber; SMART bleibt gesperrt.

### Test nach Installation

1. Auf dem iPhone und Desktop einen Wochentag öffnen und Uhrzeit sowie Zieltemperatur eingeben, ohne Fokusverlust.
2. Montag auf mehrere Tage kopieren und das Überschreiben vorhandener Zeitfenster bestätigen oder abbrechen.
3. Prüfen, dass die Anzeige keine Sekunden enthält und Änderungen erst nach „Wochenplan speichern“ dauerhaft werden.
4. Screenshots vom offenen Tageseditor, Kopierdialog und gespeichertem Wochenplan senden.

## English

- Schedule inputs preserve focus while typing; no DOM rebuild on every keystroke.
- Copy time windows to multiple weekdays using localized clickable choices, with confirmation before replacing existing windows.
- Minute-only schedule times, compact editor and save feedback.
- Existing read-only Lovelace card remains available. Legacy remains the only heating writer; SMART stays locked.
